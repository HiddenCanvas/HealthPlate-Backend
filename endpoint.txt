BASE URL: /api/v1

Semua endpoint admin wajib memakai header:
Authorization: Bearer <token admin>

Format response umum:
Success: { "success": true, "data": ..., "message": "..." }
Error:   { "success": false, "message": "..." }

ADMIN FOOD CATEGORY CRUD
GET    /admin/food-categories
GET    /admin/food-categories/:id
POST   /admin/food-categories
PUT    /admin/food-categories/:id
DELETE /admin/food-categories/:id

Body POST/PUT:
{
  "name": "Buah",
  "description": "Kategori makanan buah-buahan"
}

Response data category:
{
  "category_id": "uuid",
  "name": "Buah",
  "description": "Kategori makanan buah-buahan",
  "created_at": "timestamp",
  "updated_at": "timestamp"
}
